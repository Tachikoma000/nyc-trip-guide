# NYC Trip Guide ✦

A mobile-friendly trip companion for November 4–10, 2026, with a day-by-day itinerary, booking status, transit directions, and Google Maps links.

## Live site

https://tachikoma000.github.io/nyc-trip-guide/

GitHub Actions deploys `index.html` to GitHub Pages after changes to `main`.

If the site isn't live, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source. Then run **Actions → Deploy NYC Trip Guide to GitHub Pages → Run workflow**.

## Privacy and data

This is a public website. Do not commit QR codes, confirmation numbers, payment details, or other private travel records. In-app edits and journal entries are stored locally in each browser; they are not synchronized between devices.

## Updating the guide

Edit `index.html`, then commit to `main`. The deployment workflow will publish the updated version.
